# 拒绝焦虑！妇科主任卿荣珍带你科学认识HPV（附疫苗预约接种信息）

> 更新时间：2026-09-16 (UTC+8)

2018年ICO中国HPV和相关疾病报告显示：

- 
中国女性约98%的宫颈癌由高危型HPV导致；

- 
中国15~44岁女性中宫颈癌发病率高居恶性肿瘤第三位，成为该年龄段女性癌症死亡的第二大原因。****

一项基于美国人群的研究显示：

- 
有性行为的男性和女性，一生中感染HPV的几率高达85%~90%。

不过，广西国际壮医医院妇科主任卿荣珍表示，大家不必恐慌，HPV感染不等同于宫颈癌：

- 大多数的HPV感染（70%~90%）无症状并可在1~2年内会被自身的免疫系统清除，仅少数女性（5%~10%感染女性）呈长期持续感染，最终可能进展为癌前病变或宫颈癌。****

但是，HPV离我们每个人都不遥远，且和宫颈癌有着密不可分的关系。今天是“国际HPV知晓日”，让我们一起跟随卿荣珍，科学认识HPV，避免知识误区。

**HPV有200多种型别**
HPV的中文名是人乳头瘤病毒，目前科学家们已发现HPV有200多种型别，其中约40种型别会感染生殖道，感染部位包括阴茎皮肤、外阴、肛门、阴道、宫颈和直肠。

根据致癌性的不同，**HPV感染分为高危型别和低危型别**——

- 
高危型HPV感染是指与宫颈癌及宫颈癌前病变的发生高度相关，持续感染有可能导致恶性肿瘤，包括HPV16、18、31、33、35、39、45、51、52、56、58、59、66、68。

- 
低危型HPV感染主要与泌尿生殖系统疣和轻度鳞状上皮内病变、复发性呼吸道息肉等有关，大多是良性病变，包括HPV6、11、42、43、44等。

- 
在高危型HPV中，尤其需要被关注的是HPV16、18型，这两种分型与癌症的关系最为密切，70%以上的宫颈癌都与它们有关。

**HPV不止性传播**
HPV是一种易感染人体表皮和黏膜鳞状上皮的病毒，它可存活于皮肤和粘膜上，主要通过性行为传播，传染性强。

- **有多名性伴侣者、免疫缺陷者、过早开始性行为者，为HPV感染的高危人群。**

在每次发生性行为时正确使用避孕套，可降低感染HPV的几率，但HPV可能感染避孕套未覆盖的部位，在皮肤上存活的HPV仍能继续传染，因此避孕套无法提供避免感染 HPV 的完全保护。

除性行为外，HPV还可通过直接接触感染、母婴传播感染。

- **直接接触感染：**如手接触了HPV污染的物品后，常发生在如厕、沐浴时有可能将病毒带入生殖器官或者是生殖器官接触到带有HPV污染的浴巾、内衣等也有可能被感染。

- **母婴传播：**即母亲的生殖道感染了HPV，可能在分娩过程中传播给新生儿。
**感染HPV不一定有症状**
HPV可引起诸多皮肤、黏膜病变，不同病变有不同的临床表现，部分患者也会表现为无症状。与女性生殖道相关的较为常见的HPV感染常表现为：

- 
**尖锐湿疣：**尖锐湿疣又称生殖器疣，主要表现为生殖器周围的丘疹、角化性斑块、乳头样或菜花样赘生物等皮损，还往往合并有外阴瘙痒、带下异常等临床表现。尖锐湿疣易复发，但很少癌变。

- 
**下生殖道上皮内病变：**下生殖道上皮内瘤变是一组疾病，包括外阴鳞状上皮内病变、阴道上皮内病变、宫颈上皮内病变。外阴鳞状上皮内病变可表现为外阴瘙痒、局部皮肤破损或溃疡、丘疹、斑块、乳头状赘生物，部分患者可无症状；而阴道上皮内病变和宫颈上皮内病变的大部分患者可无明显症状，部分患者可有性交后出血或不规则阴道流血。

**如何预防HPV感染？**
HPV可以通过**规范性行为**、**不与他人共用私人生活物品**、**良好的生活习惯**减少感染几率，并且建议适龄女性**及早注射HPV疫苗（人乳头瘤病毒疫苗）**，定期进行HPV筛查。

接种HPV疫苗是目前预防宫颈癌最直接、有效的方法，且没有过性生活的人群接种效果最好。但是HPV疫苗均是预防性的，不能有效清除既已存在的HPV感染、生殖器疣或宫颈癌前病变等，不能预防已知可致宫颈癌的所有亚型感染。**HPV疫苗接种信息**
**HPV疫苗（人乳头瘤病毒疫苗）分为三种：**

- 
二价疫苗适合9-45岁之间的女性，可以有效预防HPV16型、HPV18型病毒；

- 
四价疫苗适用于9-45岁之间的女性，能够预防70%以上的宫颈癌和90%左右的尖锐湿疣；

- 
九价疫苗适用于9-45岁之间的女性，能够预防90%宫颈癌、阴道癌、宫颈病变、生殖道疣和肛门癌等多种疾病。

虽然高危型HPV与宫颈癌存在强烈的因果关系，但并不是感染HPV，就会得宫颈癌。大多数的HPV感染（70%~90%）无症状并可在1~2年内会被自身的免疫系统清除，仅少数女性（5%~10%感染女性）呈长期持续感染，最终可能进展为癌前病变或宫颈癌。
虽然HPV感染目前全世界**没有特效药**，但对于高危型HPV持续感染患者，有很多**治疗方式，如——**

- 干扰素、保妇康栓等药物局部外用促进HPV转阴；

- 运用物理治疗（包括冷冻、激光、射频消融等），去除病灶的同时可清除病灶中感染的HPV；

- 对于合并子宫颈高级别鳞状上皮内病变的患者，可以通过手术治疗，包括宫颈环形电切术（LEEP）及宫颈冷刀锥切术（CKC）；

- 民族医治疗方面，临床研究发现壮医药线点灸治疗能有效降低HPV病毒载量，促进HPV转阴。
